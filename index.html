Recuperar una copia

Importa un archivo JSON exportado previamente. Sustituirá los datos actuales.

Instalar en Android

Abre esta web desde Chrome, pulsa el menú ⋮ y selecciona «Instalar aplicación» o «Añadir a pantalla de inicio».

La opción aparecerá cuando abras la versión publicada mediante HTTPS en Chrome.

Actualización de fechas y dorsales

La aplicación descarga status-feed.json al abrirse y cuando pulsas «Actualizar estados». Para cambiar la información revisada, hay que publicar la nueva versión de ese archivo en GitHub. Las webs de organizadores no permiten una consulta automática fiable desde una PWA estática.

Privacidad y almacenamiento

Los datos se guardan en el almacenamiento local del navegador de este dispositivo. Si borras los datos de Chrome o cambias de móvil, necesitarás restaurar una copia de seguridad.
